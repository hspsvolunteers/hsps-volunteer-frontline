# 胡適志工 支援前線計分系統

皮克敏主題、等角立體風格（Isometric 3D）的四隊搶答活動互動計分系統。

## 🎮 線上體驗
- **GitHub Pages**：[https://hspsvolunteers.github.io/hsps-volunteer-frontline/](https://hspsvolunteers.github.io/hsps-volunteer-frontline/)

## ✨ 功能特色
- **破冰試玩練習題**：熱身破冰，完成後自動宣告遊戲正式開始並重置分數。
- **逐組放大物資介紹**：題目揭曉時按組別依序放大，讓主持人從容介紹小隊長與需求物資。
- **3-2-1 ➔ 開始支援倒數**：震撼音效與彩帶，倒數完成後 0.35 秒自動隱藏遮罩並解鎖計分按鈕。
- **搶答給分與排名**：支援遞減給分、完成狀態即時切換、一鍵復原上一步。
- **全向量 SVG 渲染**：皮克敏角色、舞台草地與立體配件皆為向量即時繪製，自適應 16:9 比例。
